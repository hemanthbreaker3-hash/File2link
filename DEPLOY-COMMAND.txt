FILE2LINK — SINGLE VPS DEPLOYMENT

1) Copy/paste the contents of deploy-one-command.sh into your VPS terminal,
   OR run it from the cloned project directory after obtaining the ZIP.
2) It asks for API_ID, API_HASH, OWNER_ID, optional admin/channel IDs,
   optional TMDB_API_KEY, BOT_TOKEN and MONGODB_URI. Secret inputs are hidden.
3) It clones to ~/file2link, generates a strong ADMIN_PANEL_TOKEN if needed,
   writes a private .env file, and runs deploy.vps.

The admin dashboard is available at /panel (username: admin). Retrieve its
password from the private backend .env file using: grep '^ADMIN_PANEL_TOKEN=' .env


No script can guarantee 100% success: GitHub access, VPS DNS/network, Atlas IP
allowlist, credentials, Telegram bot permissions and public BASE_URL are external
requirements. The script performs preflight validation and prints logs on failure.

After deployment, deploy.vps automatically installs and starts a Cloudflare Quick Tunnel. It prints the generated trycloudflare.com URL and synchronizes BASE_URL into .env and MongoDB. The systemd service `file2link-cloudflared` repeats this synchronization after VPS reboot. Check it with:

  sudo systemctl status file2link-cloudflared --no-pager
  sudo journalctl -u file2link-cloudflared -n 100 --no-pager
